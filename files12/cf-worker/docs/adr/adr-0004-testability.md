# ADR-4: منافذ ومحوّلات: الكود قابل للاختبار بلا شبكة

**الحالة:** معتمد (V2-01)

**السياق:** اختبارات L1 تعمل في صندوق Claude بلا شبكة وبمكتبة بايثون القياسية.

**القرار:** `core` نقي. `ports` واجهات `Protocol` (db, http, clock, kv, notifier). `adapters` وحدها تعمل I/O وتستورد المكتبات الخارجية داخل الدوال. المجالات تستقبل المنافذ حقناً ولا تستورد المحوّلات. الساعة والعشوائية تُحقن، ولا تُقرأ عند الاستيراد.

**النتائج:** المنافذ تُنشأ في المرحلة التي تستعملها أولاً.
