# ADR-7: العربية لغة افتراضية لرسائل النظام

**الحالة:** معتمد (V2-01)

**السياق:** عملاؤنا عرب ومعظم الرسائل الظاهرة لهم من النظام لا من النموذج.

**القرار:** `stores.default_language` بقيمة `ar` افتراضياً، وقيمتاه المسموحتان `ar` و`en`. رسائل العملاء بالعربية، والتعليقات والترويسات في الكود بإنجليزية بسيطة، ووثائق المشروع بالعربية.

**النتائج:** إضافة لغة جديدة تعني تعديل قيد SQL والعقد معاً (يفحصهما اختبار).
