# ADR-9: لا شيء يُنفَّذ عند الاستيراد

**الحالة:** معتمد (V2-01)

**السياق:** نشر Worker رُفض سابقاً (رمز 10021) بسبب ساعة وعشوائية عند الاستيراد.

**القرار:** لا ساعة ولا `uuid` ولا عشوائية ولا I/O ولا قراءة إعدادات على مستوى الوحدة. كل شيء يُنشأ عند أول استدعاء. يفرضه `check_conventions.py` (قاعدة `import-time`).

**النتائج:** أي ثابت يحتاج قيمة وقت التشغيل يُمرَّر معاملاً.
