# ADR-5: ميزانيات الخطة المجانية

**الحالة:** معتمد (V2-01)

**السياق:** Cloudflare Free تضع حدوداً على الطلبات الفرعية والـCPU وأحداث السجل.

**القرار:** 20 طلباً فرعياً (subrequests) لكل رسالة كحدّ أقصى، و3 مشغّلات cron كحدّ أقصى، وسطر سجل منظَّم واحد لكل رسالة، بلا أسرار ولا نص رسائل. حصة Workers Logs المجانية 200 ألف حدث يومياً بالاحتفاظ 3 أيام. كل وحدة تصرّح بميزانيتها في ترويستها (`Budget:`). `core/log_schema.py` قائمة بيضاء للحقول: ما ليس فيها يُسقَط ويُحصى.

**النتائج:** ما يُسقَط من السطر يُبلَّغ عنه للمستدعي ولا يُكتب.
