# ADR-2: الأعلام: قائمة عامة + قائمة سماح + تجاوز لكل متجر

**الحالة:** معتمد (V2-01)

**السياق:** نريد تشغيل V2 على متجر الاختبار وحده ثم توسيعه تدريجياً، بلا نشر جديد لكل خطوة.

**القرار:** متغيران في بيئة الـWorker: `V2_FLAGS` (أسماء الأعلام المفتوحة للجميع، مفصولة بفاصلة) و`V2_ALLOWLIST` (قائمة `phone_number_id` أو `*`). ومن قاعدة البيانات `stores.features` (jsonb: اسم العلم ← true/false). العلم العادي: قيمة المتجر تغلب القائمة العامة. العلم المقيَّد (`gated`، حالياً `v2_pipeline` فقط): يلزمه العلم العام وقائمة السماح معاً، وللمتجر أن يطفئه فقط ولا يفتحه. غير المُعرَّف = مطفأ. قائمة السماح الفارغة = لا أحد. الأعلام تُسجَّل في `core/flags.py` بقيمة `False` ووصف ومرحلة مالكة، والتحليل نقي لا يقرأ البيئة (المحوّل يقرؤها ويمرّرها).

**النتائج:** اسم علم خاطئ في `V2_FLAGS` لا يفتح شيئاً ويُبلَّغ عنه (`CONFIG_FLAG_UNKNOWN`).
