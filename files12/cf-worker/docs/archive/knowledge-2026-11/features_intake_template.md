# قالب جمع الميزات الجديدة (Feature intake)

املأ جدولاً واحداً لكل ميزة. لا حاجة لتفاصيل كاملة في المرة الأولى: اسم وجملة واحدة ونطاق يكفون للتصنيف.

| الحقل | الشرح | مثال |
|---|---|---|
| مفتاح الميزة | اسم قصير بحروف إنجليزية صغيرة وشرطة سفلية | `typing_indicator` |
| ماذا تفعل | جملة واحدة | يرسل مؤشر "يكتب..." قبل الرد |
| النطاق | عالمي / لكل متجر / لكل باقة (low-tier, basic, pro) | لكل متجر |
| القيمة الافتراضية | يجب أن تكون false دائماً | false |
| أين تعمل في المسار | webhook / قبل استدعاء الذكاء الاصطناعي / ai_client / إرسال الرد / قياس الاستخدام | إرسال الرد |
| تغييرات قاعدة البيانات | أعمدة أو جداول جديدة (إضافية فقط، بدون حذف أو إعادة تسمية) | عمود `typing_indicator boolean default false` في stores |
| مدخلات جديدة | متغيرات بيئة، مفاتيح، استدعاءات خارجية جديدة | لا شيء |
| هل تغيّر ما يُرسل إلى OpenRouter أو Meta؟ | نعم / لا (وماذا بالضبط) | لا |
| هل تغيّر حساب الاستخدام أو السقوف؟ | نعم / لا | لا |
| سلوك الاختبار | ما المتوقع عند true وما المتوقع عند false | true: يُرسل المؤشر. false: لا يتغير شيء |
| الأولوية | الآن / بعد المرحلة 6 / بعد الإطلاق | بعد المرحلة 6 |

قاعدة ثابتة: إذا كانت false فالنظام يتصرف **بالضبط** كنسخة Render الحالية.
